# Release Notes — CareConnect Demo Portal

**Release:** 0.2 (fictional example)  
**Date:** 18 November 2026  
**Status:** Demonstration only

## Summary
This fictional release illustrates how a documentation writer might communicate a small change to appointment-request status messaging.

## What's changed
- The request status label now displays **Pending confirmation** after a request is submitted.
- The confirmation panel explains that submission does not mean the appointment is booked.
- The help content links users to the appointment section of the user guide.

## User impact
Users receive a clearer explanation of the state of a submitted request. They should wait for confirmation from the organisation before treating an appointment as booked.

## Documentation updated
- Software User Guide — appointment request workflow.
- Troubleshooting and FAQ content — status explanation.
- Support response template — explanation of pending status.

## Validation required before publication
A product owner must confirm the exact interface wording, the state transition, and the supported confirmation channel. This sample does not describe a real software release.
